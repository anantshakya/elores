# ELORES Full Local Ecommerce

This build is intended to be tested locally first. Read `README_LOCAL.md` for Windows/XAMPP startup instructions and `IMPLEMENTATION_STATUS.md` for the documentation-to-feature implementation map.

Quick start:
1. Put this folder at `C:\xampp\htdocs\elores`.
2. Start XAMPP MySQL.
3. Create MySQL database `elores_db`.
4. Run `setup-local-windows.bat` once.
5. Run `start-local-backend.bat`.
6. Run `start-local-frontend.bat`.
7. Open `http://localhost:5173` and `http://localhost:5173/admin`.
